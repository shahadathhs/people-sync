# PeopleSync

PeopleSync is a comprehensive team management and communication platform for multiple companies. It combines HR functionalities with real-time team collaboration tools.  

## Features

- **Shift & Attendance Management**  
  Branch-based geolocation validation with timezone-aware scheduling. Daily shift logs, clock-in/out tracking, and automated overtime handling with approval workflow.

- **Payroll Tracking**  
  Base salary, hourly rates, overtime, deductions, and net pay. Payroll periods with detailed line items and approval process.

- **Recognition System**  
  Badges, comments, and reactions to recognize employees’ achievements and contributions.

- **Survey & Poll System**  
  Multi-type questions (open-ended, multiple choice, rating) with assignments to users, departments, or branches. Supports timezone-aware scheduling for multi-location operations.

- **Team Communication**  
  One-to-one and group messaging, audio calls, video calls, and file sharing. Built to support multiple employees under admins for structured communication.

- **Multi-Company Support**  
  Designed to connect teams across multiple companies with consistent HR processes and unified communication.

## Note

> Database schema and design are currently ongoing and subject to updates as the project evolves.
